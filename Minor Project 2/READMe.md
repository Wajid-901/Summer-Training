# Responsive Product Landing Page

## Project Overview

This project is a **Responsive Product Landing Page** created as **Week 02 Minor Project** for the Web Development course.

The landing page showcases a smartwatch product and is designed to be responsive across mobile, tablet, and desktop devices.

---

## Features

- Responsive Navigation Bar
- Hero Section
- Features Section
- Benefits Section
- Customer Testimonials
- Pricing / Call-to-Action Section
- Footer with Contact Information and Social Media Links

---

## Technologies Used

- HTML5
- Tailwind CSS
- CSS Flexbox
- CSS Grid

---

## Responsive Design

The website is responsive and works on:

- Mobile
- Tablet
- Desktop
